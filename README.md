# Yaswanth Kasani - Portfolio Website

A clean, modern, and fully responsive personal portfolio website showcasing my skills, experience, projects, and contact information.

## 🚀 Live Demo
Visit the live portfolio on GitHub Pages:
**[https://yaswanth-kasani.github.io/portfolio/](https://yaswanth-kasani.github.io/portfolio/)**

---

## 🛠️ Built With
- **HTML5** - Semantic page markup
- **CSS3** - Custom styling, Flexbox layout, and CSS media queries for full responsiveness
- **JavaScript (ES6+)** - Dynamic navigation and interactive UI elements
- **Google Fonts** - Poppins typography
